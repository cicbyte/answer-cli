### CLI 工具 README 写作要点

- 示例中展示终端输出，让用户知道预期结果
- 用户输入的命令加 `$` 前缀，程序输出不加前缀
- 如果支持 Tab 补全和 Shell 配置，值得提及
- 如果有类似工具，增加「对比」章节（如「为什么不选 X？」）
