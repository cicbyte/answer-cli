### 通用 README 写作要点

- 保持简短 — 通用项目不需要面面俱到的文档
- 聚焦「是什么」和「怎么用」 — 除非要求否则跳过内部架构
- 一个好的快速开始比详细的配置文档更有价值
- README 超过 200 行时添加目录
