### 框架 README 写作要点

- 「为什么」章节至关重要 — 框架靠理念竞争
- 核心概念应教授心智模型，而非罗列功能
- 快速开始控制在 5 条命令以内
- 链接到详细文档 — README 是入口，不是文档本身
- 尽早展示框架独特的语法或 API 模式
