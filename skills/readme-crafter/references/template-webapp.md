### Web 应用 README 写作要点

- 主截图至关重要 — 这是第一印象
- 展示应用运行效果，而不仅仅是代码
- 简要提及技术栈 — 开发者想知道技术选型
- 自托管应用需要部署章节
- 路线图表明项目活跃开发，吸引贡献者
