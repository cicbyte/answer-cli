# 工作流模式

## 顺序工作流

复杂任务拆分为清晰的顺序步骤。在 SKILL.md 开头给出流程概览：

```markdown
填写 PDF 表单包含以下步骤：

1. 分析表单（运行 analyze_form.py）
2. 创建字段映射（编辑 fields.json）
3. 验证映射（运行 validate_fields.py）
4. 填写表单（运行 fill_form.py）
5. 验证输出（运行 verify_output.py）
```

## 条件工作流

包含分支逻辑的任务，引导 Claude 在决策点做出选择：

```markdown
1. 确定操作类型：
   **创建新内容？** → 执行"创建工作流"
   **编辑已有内容？** → 执行"编辑工作流"

2. 创建工作流：[步骤]
3. 编辑工作流：[步骤]
```
