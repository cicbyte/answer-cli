# 输出模式

当 skill 需要产生一致、高质量的输出时使用这些模式。

## 模板模式

为输出格式提供模板，根据需求严格程度调整。

**严格要求（如 API 响应、数据格式）：**

```markdown
## 报告结构

必须使用以下模板结构：

# [分析标题]

## 概要
[一段话概述关键发现]

## 关键发现
- 发现 1 及支撑数据
- 发现 2 及支撑数据

## 建议
1. 具体可执行的建议
2. 具体可执行的建议
```

**灵活指导（允许根据场景调整）：**

```markdown
## 报告结构

以下是默认格式，可根据实际情况调整：

# [分析标题]

## 概要
[概述内容]

## 关键发现
[根据实际发现调整章节]

## 建议
[根据具体场景定制]
```

## 示例模式

输出质量依赖示例时，提供输入/输出对：

```markdown
## 提交信息格式

按以下示例生成提交信息：

**示例 1：**
输入：添加了基于 JWT 的用户认证
输出：
```
feat(auth): 实现 JWT 认证

添加登录端点和 Token 验证中间件
```

**示例 2：**
输入：修复报告中日期显示不正确的问题
输出：
```
fix(reports): 修正时区转换中的日期格式

报告生成统一使用 UTC 时间戳
```

格式：type(scope): 简要描述，然后详细说明。
```

示例比纯文字描述更能帮助 Claude 理解期望的风格和详细程度。
