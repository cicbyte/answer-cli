# Collection — 数据模型

### `RespBody`

- `code` `integer` — http code
- `data`  — response data
- `msg` `string` — response message
- `reason` `string` — reason key

---

### `CollectionSwitchReq`

- `bookmark` `boolean`
- `group_id` `string` **(必填)**
- `object_id` `string` **(必填)**

---

### `CollectionSwitchResp`

- `object_collection_count` `integer`
