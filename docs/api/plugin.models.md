# Plugin — 数据模型

### `RespBody`

- `code` `integer` — http code
- `data`  — response data
- `msg` `string` — response message
- `reason` `string` — reason key

---

### `EmbedConfig`

- `enable` `boolean`
- `platform` `string`

### `GetPluginListResp`

- `description` `string`
- `enabled` `boolean`
- `have_config` `boolean`
- `link` `string`
- `name` `string`
- `slug_name` `string`
- `version` `string`
